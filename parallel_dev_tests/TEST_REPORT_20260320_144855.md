## Issues Encountered

### 1. Token Budget Configuration
**Problem:** Initial config had `token_budget = 500000` which exceeded vLLM's `max_model_len = 131072`.

**Error:**
```
max_tokens=499127 cannot be greater than max_model_len=max_total_tokens=131072
```

**Fix:** Reduced `token_budget` to 16000 with 2000 safety margin.

### 2. Stream Decoding Errors
**Problem:** 3 out of 4 instances failed with stream decoding errors.

**Error:**
```
Error: Stream error: error decoding response body
```

**Possible Causes:**
- vLLM streaming incompatibility with selfware's streaming client
- Network/buffer issues with large concurrent requests
- Model output format issues

### 3. Slow Processing / Hanging
**Problem:** Portfolio instance hung at "Step 2 Executing..." for 5+ minutes without creating files.

**Observations:**
- GPU utilization stayed at 100%
- vLLM was processing but responses were slow/stuck
- No file write operations occurred

## Root Cause Analysis

### vLLM Configuration Issues
1. **max_model_len too low:** 131072 vs model's capability of 1M tokens
2. **Streaming compatibility:** Tool calling with streaming may have issues
3. **Concurrent request handling:** 4 parallel requests may overwhelm the server

### Selfware Configuration Issues
1. **Token budget calculation:** Needs better alignment with server capabilities
2. **Streaming error handling:** Should retry on stream errors
3. **Timeout handling:** Step timeouts may not be working correctly
