3. **P1 — Automatic verification subprocesses still inherit global credentials.** `language_qa::run_stage` executes project-controlled programs without the environment sanitizer used by the hardened tools. Evidence: [local probe](/tmp/selfware-review-20260921/timeout-env-probe.log), [synthetic-credential marker](/tmp/selfware-review-20260921/qa-timeout/inherited-marker). 4. **P1 — An untrusted repository can direct a global API key to a localhost listener.** The credential-origin gate exempts local endpoints, but the resolved global key remains attached to the client. A scratch, untrusted `selfware.toml` selecting `http://127.0.0.1:18091/v1` loaded successfully with a synthetic globally exported key. A listener at that address would receive it when the client sends a request. Local transport does not establish that the listener is authorized to receive a provider credential. Gate credential origin independently from the plaintext-transport check, including model profiles. Source: [loader.rs:746](/Users/ivo/selfware/src/config/loader.rs:746). Evidence: [configuration-only reproduction](/tmp/selfware-review-20260921/config-probe.log). This probe did not send an HTTP request.

5. **P2 — HTTP secret checking can be bypassed by changing the payload location.** The same synthetic `ghp_…` value is rejected in a URL but accepted in a POST body and custom header. The HTTP tool then forwards those fields without an equivalent check. Apply a consistent outbound-content policy to URL, body, and headers, with explicit treatment for intentionally configured authentication. Sources: [validation.rs:830](/Users/ivo/selfware/src/safety/checker/validation.rs:830), [http.rs:168](/Users/ivo/selfware/src/tools/http.rs:168). Evidence: [checker-only reproduction](/tmp/selfware-review-20260921/classification-probe.log); no outbound request was executed.

6. **P2 — Workspace graph data can inject JavaScript into the VS Code webview.** The extension loads workspace-controlled `codegraph.json`, stringifies it, and interpolates it directly inside an executable script block. A label containing `</script><script>…</script>` breaks out of that block. The rendered page has no CSP; `fusion_group` is also inserted into `innerHTML` without escaping. The reproduction rendered a harmless canary script into the generated HTML. Encode script-embedded JSON safely, escape all graph-derived markup, and add a nonce-based CSP. This establishes webview script injection, not demonstrated host-level code execution. Sources: [webview.ts:10](/Users/ivo/selfware/vscode-selfware/src/webview.ts:10), [webview.ts:59](/Users/ivo/selfware/vscode-selfware/src/webview.ts:59), [webview.ts:254](/Users/ivo/selfware/vscode-selfware/src/webview.ts:254), [extension.ts:84](/Users/ivo/selfware/vscode-selfware/src/extension.ts:84). 7. **P2 — A scoped prohibition incorrectly turns an implementation task into a read-only task.** The live prompt asked to fix `calculator.py`, “do not modify test_calculator.py,” and “report the result.” The classifier sees both a report word and any editing prohibition, overriding its positive mutation classification. The resulting checkpoint contains the read-only-report gate. This disables mutation-required safeguards for a task that explicitly requires an edit. Distinguish a global prohibition from a protected-file constraint. Source: [task_policy.rs:89](/Users/ivo/selfware/src/agent/task_policy.rs:89). Evidence: [original live messages](/tmp/selfware-review-20260921/e2e-budget-messages.json).

8. **P2 — QA timeouts do not stop the timed-out process.** Wrapping `Command::output()` in `tokio::time::timeout` drops the future without terminating the child. A local seven-second stub hit the five-second QA timeout and then wrote a marker after the stage had returned failure. It can continue modifying files or holding locks during subsequent work. The same pattern occurs in `VerificationGate::run_cargo_test` and post-edit commands. Use owned process-group cancellation/reaping for timeout and cancellation paths. Sources: [language_qa.rs:70](/Users/ivo/selfware/src/testing/language_qa.rs:70), [verification.rs:946](/Users/ivo/selfware/src/testing/verification.rs:946). Evidence: [timeout reproduction](/tmp/selfware-review-20260921/timeout-env-probe.log). The synthetic child finished naturally after the observation.

9. **P2 — Truncated SSE can be returned as a successful completion.** A local mock sent one valid content event and closed, without `[DONE]` or a `finish_reason`. `collect()` returned `Ok` with the incomplete text and `finish_reason=None`. The current check rejects only a stream with zero parsed events; it does not establish completion. Require an accepted terminal indication or return a typed incomplete-stream outcome while retaining usage. Source: [streaming.rs:355](/Users/ivo/selfware/src/api/streaming.rs:355). Evidence: [mock transport reproduction](/tmp/selfware-review-20260921/stream-probe.log).

10. **P2 — Auto-continuation checkpoints double-count the current segment's wall time.** `maybe_auto_continue` adds elapsed time into `prior_elapsed_secs` and immediately saves a checkpoint. `to_checkpoint` calls `budget_elapsed_secs` again while the old start time is still active; the start time is reset only in `continue_execution`. For an initial ten-second segment, the boundary checkpoint records roughly twenty seconds. A restart therefore consumes budget that was never spent. Accumulate elapsed time and reset the baseline together before persistence. Sources: [task_runner.rs:970](/Users/ivo/selfware/src/agent/task_runner.rs:970), [checkpointing.rs:472](/Users/ivo/selfware/src/agent/checkpointing.rs:472), [task_runner.rs:802](/Users/ivo/selfware/src/agent/task_runner.rs:802). Evidence: source-level control-flow review.

11. **P2 — Forced checkpointing reports success when there is no checkpoint manager.** `save_checkpoint_forced` returns `Ok(())` for `None`, so auto-continuation can emit “checkpointed and chaining” despite writing nothing. If checkpoint setup failed, the promised restart point does not exist. Return a typed unavailable-storage error for forced persistence and make the continuation handle that outcome. Source: [checkpointing.rs:525](/Users/ivo/selfware/src/agent/checkpointing.rs:525). Evidence: source-level control-flow review.

12. **P2 — Permission failures can be mislabeled as iteration exhaustion.** The auto-edit CLI test correctly stopped because `shell_exec` required confirmation in a noninteractive run, but its JSON `failure_mode` said `MAX_ITERATIONS` after only three iterations. 13. **P2 — Playwright bridge stderr is piped but never drained.** Startup captures stdin/stdout, but leaves stderr unread. A sufficiently noisy bridge/browser error path can fill the pipe and stall the child, making subsequent commands time out. Drain stderr concurrently into a bounded diagnostic buffer, or inherit it deliberately. Source: [page_controller.rs:112](/Users/ivo/selfware/src/tools/page_controller.rs:112). 14. **P2 — Evolution protection omits repository instructions.** `is_protected("AGENTS.md")` and `is_protected("src/AGENTS.md")` both return false. The daemon's protection gate therefore does not preserve those instructions, and the apply path permits nested instruction files under `src/` or `docs/`. Evidence: [protection probe](/tmp/selfware-review-20260921/classification-probe.log). No instruction file was modified.

15. **P2 — Zed's advertised binary fallback never reaches the release binary.** If `worktree.which("selfware")` returns `None`, the next candidate is always `Some(target/debug/selfware)`, and the loop returns it without checking existence. A workspace with only a release build therefore attempts a missing debug binary; later candidates are unreachable. Resolve existence before caching or require an explicit configured binary when discovery is unavailable. Source: [zed lib.rs:56](/Users/ivo/selfware/zed-extension/src/lib.rs:56). Evidence: source inspection, not an editor-host runtime test.
