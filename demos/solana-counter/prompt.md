Build a Solana counter program using Anchor framework:

1. Initialize a new Anchor project called "counter"
2. Implement a Counter account with a count field (u64)
3. Add an "initialize" instruction that creates the counter
4. Add an "increment" instruction that increases count by 1
5. Add a "decrement" instruction that decreases count by 1 (don't go below 0)
6. Write tests that verify all three instructions
7. Build the program
8. Deploy to localnet
